# Свой сервер RustDesk на Windows

Инструкция и рабочие скрипты для **собственного сервера RustDesk** (hbbs + hbbr) на Windows.
Клиенты подключаются напрямую к вашему серверу, а не через облако RustDesk.

Схема простая:

```
телефон/ноутбук  ──►  hbbs (ID-сервер)  ──►  hbbr (релей)  ◄──  второй компьютер
                        21116 TCP/UDP         21117 TCP
```

- **hbbs** — «сервер знакомств»: выдаёт ID, сводит клиентов, помогает пробить NAT.
- **hbbr** — релей: передаёт трафик, если напрямую соединиться не получилось.
- **ключ** — пара файлов `id_ed25519` (приватный, только на сервере) и `id_ed25519.pub` (публичный, его вводим в клиенте).

Проверено на: Windows Server 2025, RustDesk Server **1.1.16**, клиент RustDesk **1.5.0+68**.

---

## 1. Порты

| Порт | Протокол | Кто слушает | Зачем |
|---|---|---|---|
| 21115 | TCP | hbbs | проверка типа NAT |
| 21116 | TCP + **UDP** | hbbs | регистрация ID, обмен сигналами, пробивка NAT |
| 21117 | TCP | hbbr | релей (передача трафика) |
| 21118 | TCP | hbbs | веб-клиент |
| 21119 | TCP | hbbr | веб-клиент |

UDP 21116 — самый важный: без него часть клиентов не подключится.

Правила брандмауэра создаются скриптом `scripts/firewall.ps1`.

## 2. Установка

1. Скачайте `RustDeskServer.Setup.exe` из раздела **Releases** этого репозитория (или с официального сайта rustdesk.com).
2. Установите. Файлы появятся в папке вида
   `C:\Users\<пользователь>\AppData\Local\RustDeskServer\x86_64`
   (hbbs.exe, hbbr.exe, rustdesk-utils.exe).
3. Один раз запустите `hbbs.exe` — он создаст в своей папке два файла:
   - `id_ed25519` — **приватный** ключ (88 символов),
   - `id_ed25519.pub` — **публичный** ключ (44 символа).
4. Сохраните оба файла в надёжном месте. Потеряете приватный — все клиенты отвалятся с ошибкой `Key mismatch`.
5. Откройте порты: правый клик по `scripts\firewall.ps1` → «Выполнить с помощью PowerShell» (от администратора).
6. Подставьте свои значения в `scripts\run-hbbs.cmd` и `scripts\run-hbbr.cmd`:
   - `SERVER_IP` — внешний IP или домен сервера,
   - `KEY` — содержимое файла `id_ed25519` (приватный ключ, 88 символов).
7. Запустите `scripts\start-server.bat` — стартуют оба процесса, логи пишутся в `C:\ProgramData\RustDesk\`.

---

## 3. Ключи: где какой

| Файл | Длина | Куда | Можно публиковать? |
|---|---|---|---|
| `id_ed25519` | 88 символов | параметр `-k` у hbbs и hbbr, файл на сервере | **Нет, никогда** |
| `id_ed25519.pub` | 44 символа | поле **Key** в настройках клиента | Да, это публичная часть |

В логе при старте видно, что сервер принял именно приватный ключ:

```
INFO The key is a crypto private key
INFO Key: <публичный ключ, 44 символа>
```

Вторая строка — это и есть значение для клиентов.

## 4. Настройка клиента

В RustDesk откройте **Настройки → Сеть** и укажите:

- **ID-сервер** — IP или домен вашего сервера (например `203.0.113.10`),
- **Сервер релея** — тот же адрес (порт 21117 подставится сам),
- **Ключ** — содержимое `id_ed25519.pub`.

Нажмите «Применить». В трее должно появиться «Готов к работе» и ваш ID.

Те же три поля можно задать сразу при установке клиента (в установщике есть раздел «Сеть»).

> Пароль на подключение задайте постоянный: **Настройки → Безопасность → Постоянный пароль**.
> Иначе после каждой перезагрузки пароль будет новый.

## 5. Автозапуск после перезагрузки

Сервер RustDesk — обычные консольные программы, службой они не становятся. Есть два способа.

### Способ А: автологин + папка «Автозагрузка» (используется здесь)

1. Включён автологин пользователя (утилита Autologon от Sysinternals).
2. В папке автозагрузки лежит ярлык на `scripts\start-server.bat`.

Минус: нужен автологин. Плюс: работает без прав администратора.

### Способ Б: Планировщик заданий

1. «Планировщик заданий» → «Создать задачу».
2. Триггер: **При входе в систему** (или «При запуске»).
3. Действие: запуск программы `C:\...\scripts\start-server.bat`.
4. Галочка «Выполнять с наивысшими правами».

Если нужен запуск без входа пользователя — «Выполнять независимо от того, вошёл ли пользователь» и сохранить пароль учётной записи.

## 6. Раздача интернета по Wi-Fi (необязательно)

На этом сервере настроена «Размещённая сеть» Windows (`MTS_WIFI`, 192.168.137.1) — к ней подключаются телефоны и получают интернет через общий доступ (ICS).

Скрипты:

- `scripts\hotspot-service.ps1` — поднимает сеть и включает общий доступ один раз;
- `scripts\hotspot-watchdog.ps1` — проверяет, что сеть и адрес 192.168.137.1 на месте, и чинит при необходимости (запускать по расписанию, например каждые 5 минут).

Требования: Wi-Fi адаптер с поддержкой hosted network, службы `WLAN AutoConfig` и `SharedAccess` (Общий доступ к подключению к Интернету).

Проверить вручную:

```powershell
netsh wlan show hostednetwork
netsh wlan start hostednetwork
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -like '192.168.137.*' }
```

Если «Состояние: Недоступно» — адаптер не поддерживает режим точки доступа или выключен драйвер.

## 7. Диагностика

Логи:

- `C:\ProgramData\RustDesk\hbbs.log`
- `C:\ProgramData\RustDesk\hbbr.log`
- `C:\ProgramData\RustDesk\hotspot.log`, `hotspot-watchdog.log`

Быстрая проверка после перезагрузки — `scripts\verify-boot.ps1` (подождать 60 секунд, отчёт появится в `C:\ProgramData\RustDesk\verify-report.txt` и на рабочем столе). Скрипт проверяет: службы, процессы hbbs/hbbr, порты, активные подключения, клиент RustDesk, размещённую сеть, IP-адреса и ошибки в журнале Windows.

### Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| `Key mismatch` в логе клиента | в клиенте другой ключ | вписать содержимое `id_ed25519.pub` без пробелов |
| Клиент не подключается, ID не появляется | закрыт UDP 21116 | открыть порты, проверить провайдера |
| `Error 10048` / порт занят | запущено два hbbs | убить лишний процесс, оставить один |
| `dns error ... (os error 11001)` в логе | нет доступа к api.rustdesk.com | не влияет на работу, это проверка версии |
| После перезагрузки ничего не работает | не сработал автозапуск | проверить ярлык/задачу, запустить `start-server.bat` вручную |
| Телефон подключился к Wi-Fi, но интернета нет | слетел общий доступ (ICS) | `hotspot-watchdog.ps1` |

## 8. Безопасность

- Приватный ключ `id_ed25519` и пароли — **только на сервере**. В этот репозиторий они не попадают, в скриптах стоят заглушки `YOUR_SERVER_IP` и `YOUR_PRIVATE_KEY`.
- Порт 21114 (веб-консоль) наружу не открывайте, если не пользуетесь ею.
- Обновляйте сервер: новые версии — на GitHub `rustdesk/rustdesk-server` и на rustdesk.com.
- В клиенте включите постоянный пароль и, по желанию, «Разрешить только определённым ID».
